# ChatGPT 智慧介面 100 例：教師互動教學素材庫

## 使用方式

直接以 Chrome、Edge 或 Safari 開啟 `index.html`，無需安裝或連線。全部 100 個案例及提示詞已嵌入網頁，不需要外部檔案。

1. 用搜尋或分類挑選範例。
2. 按「查看提示詞」，再按「複製提示詞」或「複製並開啟 ChatGPT」。
3. 在 ChatGPT 貼上提示詞並送出，依介面輸出的結果實際驗證，再帶入課堂。
4. 收藏與備課清單會以瀏覽器 localStorage 儲存。可以用「備份收藏與備課」產出 JSON；改用其他瀏覽器時可匯入。
5. 可匯出全部、搜尋結果或單筆提示詞的 TXT，另可匯出 CSV。備課工作台可匯出教案草稿。

## 網站功能

- 100 筆範例，依 17 個領域分類，搜尋、篩選、分頁、隨機靈感
- 每筆皆有完整實作提示詞、核心互動、專屬驗收規格、課堂應用流程
- 單筆、批次 TXT 與 CSV 匯出、複製、開啟 ChatGPT
- 收藏、備課清單、JSON 匯出匯入
- 教學流程指南、教案草稿及六項作品自評檢核
- 繁體中文、RWD、深色模式、離線執行

## 資料與版本說明

此版本根據先前對話整理的範例集建置。核對後舊清單實際為 69 筆，所以以「線性規劃可行域探索」補足第 70 筆，新增 71～100 保持原編號。案例標題彼此不重複。

網站提供 **建立智慧介面的完整提示詞**，不是預先製作的 100 個實際模擬程式。生成結果仍應由教師檢查正確性與互動性。

## GitHub Pages

將 `index.html` 與 `README.md` 放進 GitHub 儲存庫根目錄，前往 Settings → Pages → Deploy from a branch → main / root，便可發佈網站。所有資料已內嵌在 `index.html`。

## 個資提醒

請勿將未經授權的學生姓名、成績或敏感個資貼入 ChatGPT 提示詞。
